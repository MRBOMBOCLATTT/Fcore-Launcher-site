# FCore Launcher website

Landing page for [FCore Launcher](https://github.com/MRBOMBOCLATTT/FCore-Launcher). One static `index.html`, no build step.

- Russian and English, switched in the header.
- The download button and the changelog are read from GitHub Releases of the launcher repository.
- Screenshots live in `assets/shots/` (`home`, `builds`, `content`, each with `-ru` and `-en`).

Hosted with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
